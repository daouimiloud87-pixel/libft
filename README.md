# Libft

## Description
Libft is the first library project of the 42 curriculum. The goal is to re-implement a set of standard C library functions from scratch, add a number of useful utility functions, and bundle everything into a static library (libft.a) that can be reused in all later 42 projects.
Building this library teaches:

*How standard functions  work internally.*
*Manual memory management (malloc / free), pointer arithmetic and edge-case handling.*
*Writing a clean, Norm-compliant codebase and building it with a Makefile.*
